
# SWYNEX – Final Cloud Deployment Case Study

## 1. Project Overview
This project demonstrates a complete cloud deployment case study, including cloud architecture, static website deployment, monitoring, cost awareness, and lessons learned.

## 2. Cloud Architecture
The project uses a simple cloud architecture with:
- Compute: GitHub Pages hosting
- Storage: GitHub repository
- Networking: HTTPS
- Identity and Access: GitHub account and repository permissions

Architecture Documentation:
https://github.com/aasik20/SWYNEX-Cloud-Architecture-Outline

## 3. Cloud Deployment
A static website was deployed using GitHub Pages.

Live Website:
https://aasik20.github.io/SWYNEX-Basic-Cloud-Deployment/

Deployment Platform: GitHub Pages

## 4. Monitoring and Cost Awareness
Monitoring and cost awareness concepts were documented, including uptime monitoring and GitHub Actions workflow automation.

Monitoring Documentation:

- Understanding basic cloud architecture.
- Deploying a static website using GitHub Pages.
- Understanding HTTPS and cloud hosting.

- Understanding cloud monitoring and cost awareness.
- Documenting cloud deployment processes.
